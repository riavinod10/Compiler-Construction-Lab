# Compiler Construction Lab

This repository contains lab exercises, implementations, and assignments completed as part of the Compiler Construction course. It covers fundamental compiler design concepts, including lexical analysis, syntax analysis, parsing techniques, syntax tree generation, intermediate code generation, and backpatching using LEX, YACC, regular expressions, and Python.

## Concepts Covered

- Compiler phases and the role of LEX and YACC
- Lexical analysis and token recognition
- Regular expressions and pattern matching
- Comment and whitespace removal
- Token counting and symbol table generation
- Syntax analysis and grammar-based parsing
- Arithmetic expression parsing and postfix evaluation
- Syntax tree construction
- Recursive descent parsing
- Tokenization of pseudo languages
- Intermediate code generation and three-address code
- Control flow and Boolean expression translation
- Backpatching and placeholder management

## Technologies Used

- **LEX** – Lexical analysis and tokenization
- **YACC** – Syntax analysis and grammar-based parsing
- **Python** – Selected implementations and exercises
- **Jupyter Notebook** – Interactive code development and execution
- **Git and GitHub** – Version control and source code management

## Learning Outcomes

Through these experiments, the repository demonstrates the practical application of compiler construction principles, from recognizing tokens and validating syntax to building syntax trees and generating intermediate representations of source code.

## Purpose

This repository serves as an academic record of Compiler Construction lab work and a reference for revising lexical analysis, parsing, and intermediate code generation techniques.
